# 💱 Conversor de Moedas - Integration Master (PycodeBR)

## 📋 Descrição

Este projeto foi desenvolvido com base em uma aula do curso **Integration Master** da **PycodeBR Treinamentos**.

É um conversor de moedas simples feito em Python, que consulta taxas de câmbio em tempo real via API e permite ao usuário converter entre diferentes moedas diretamente pelo terminal.

🧪 Ideal para praticar:
- Consumo de APIs com Python


## 🛠️ Tecnologias Utilizadas

- **Python** → Linguagem principal do projeto  
- **requests** → Requisições HTTP para consultar a API de câmbio  


## 🚀 Como Executar o Projeto

### Passo 1: Clonar o Repositório
```bash
git clone https://github.com/lyraleo23/integration-master-conversor-moedas.git
cd integration-master-conversor-moedas
```

### Passo 2: Criar um Ambiente Virtual (opcional, mas recomendado)
```bash
python -m venv venv
source venv/bin/activate  # No Windows: venv\Scripts\activate
```

### Passo 3: Executar o Script
```bash
python main.py
```
